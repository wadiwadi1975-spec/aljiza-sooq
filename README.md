# AlJeeza Sooq | سوق الجيزة

منصة سوق رقمي محلي (MVP) — تربط أصحاب المحلات والمعارض والمصانع والموردين بالمشترين، تبدأ من الجيزة.

## المتطلبات
- Node.js 18 أو أحدث

## التشغيل محليًا
```bash
npm install
node seed.js     # ينشئ قاعدة البيانات ويضيف بيانات تجريبية محدودة (مرة واحدة فقط)
node app.js      # يشغّل الخادم على http://localhost:3000
```

ثم افتح المتصفح على: http://localhost:3000

## البنية التقنية
- **Backend:** Node.js + Express
- **قاعدة البيانات:** SQLite (عبر better-sqlite3) — ملف واحد في `data/aljeeza.db`، لا حاجة لخادم قاعدة بيانات منفصل
- **الجلسات:** express-session مع تخزين SQLite (`data/sessions.db`)
- **الواجهات:** EJS + CSS مخصص (RTL بالكامل)، بدون إطار عمل frontend خارجي — يعمل بدون بناء (build) إضافي
- **رفع الصور:** multer (تُحفظ في `public/uploads`)

## الكيانات (Entities) في قاعدة البيانات
User, Vendor, Store, Product, Category, ProductImage, Favorite, Follow,
Message, Review, Advertisement, Subscription, Report, Location, Inquiry

## الأدوار والصلاحيات
- **زائر:** تصفح وبحث بدون تسجيل
- **مشتري:** حساب + مفضلة + متابعة + رسائل + تقييمات + بلاغات
- **عارض:** بعد الموافقة من الإدارة يمكنه إنشاء متجر وإدارة منتجاته فقط (لا يمكنه تعديل منتجات عارض آخر — محمي في `routes/vendor.js` عبر `ownsProduct`)
- **مدير:** لوحة كاملة لإدارة المستخدمين، المتاجر، المنتجات، التصنيفات، التقييمات، البلاغات، والإعلانات المميزة

## النشر (Deployment)
هذا تطبيق Node.js كامل (وليس ملف HTML ثابت)، لذا يحتاج بيئة تشغّل Node مع تخزين دائم للملف `data/aljeeza.db`
(مثل: Render, Railway, a VPS, أو أي مزوّد يدعم Node.js). لا يمكن نشره عبر Netlify Drop لأنه ليس موقعًا ثابتًا.

## نقاط التوسع المستقبلية (البنية جاهزة لها)
- الدفع الإلكتروني (جدول Subscription جاهز لباقات مدفوعة)
- الشحن والتوصيل
- تطبيقات iOS/Android (يمكن بناء REST API فوق نفس قاعدة البيانات)
- الخرائط (حقل Location قابل للتوسع بإحداثيات)
- إشعارات Push
- عروض وخصومات
- بحث وتوصيات بالذكاء الاصطناعي
- تعدد المدن والدول (جدول Location مصمم لذلك مسبقًا)
- دعم اللغة الإنجليزية (البنية تفصل المحتوى عن العرض، يمكن إضافة i18n)
